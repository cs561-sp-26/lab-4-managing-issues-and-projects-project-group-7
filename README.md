### Pros of GitHub Projects
- Everything in one place. Issues, pull requests, and tasks are tied together, so you’re not bouncing between tools.
- Great team visibility. Everyone can see what’s in progress, blocked, or done at a glance.
- Work great with Agile, Kanban, Scrum, development workflows

### Cons of GitHub Projects
- Messy, and confusing at times. 
- Not very much project management orientated. 
- Some of the pages feel repetative. 

## Tool Chosen
GitHub Projects

## Rationale
We used GitHub Projects because it keeps all our repo code and issues in one place. This keep us from having to jump back and forth between applications. We could easily see our teams updates in real time, since everything is link together on GitHub.
